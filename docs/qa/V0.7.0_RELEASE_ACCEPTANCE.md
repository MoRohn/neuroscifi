# NeuroSciFi 0.7.0 release acceptance

This document judges the 0.7.0 release candidate against the 15 release criteria (`RELEASE_DECISIONS.md` §4), the 12
acceptance scenarios (S1 to S12) and the Presence acceptance checks A to L (`.omc/autopilot/spec-presence.md`). Each
judgement points to its evidence. It is a judgement from recorded evidence, not a new test run.

**Status words.** PASS: executed by an independent tester and passed. PASS-with-limitation: passed, with a named limit on
what was exercised. FAIL: executed and failed. BLOCKED: cannot be executed in this environment. NOT TESTED: could run
here, was not run. "Fix-lane live" means only the fixing lane ran it live (not independent). Retest reports: UAT evidence
(not in repo) `retest/r4/REPORT.md`, `retest/r5/REPORT.md`.

Evidence that lives outside the repository is written as "UAT evidence (not in repo)" with a path relative to the
session's `v07/` folder (`uat/`, `retest/`).

## Verdict

**Release candidate; not accepted. Open High: T1-07 (ambiguous-subject sense) and SEC-G-E1 (no entailment check for
supported-cited sentences, pre-existing); owner decisions OD-5, OD-6.** Not production-ready.

1. **Open High defect, T1-07.** "When was Rust first released?" is answered about the video game (R4, 2 of 2 runs).
   Synthesis has no notion of word sense, so any page naming "Rust" counts as on-subject. Python is answered correctly
   (R5). The proposed word-sense design is in `RELEASE_DECISIONS.md` §7. Owner decision OD-5.
2. **Open High (security, pre-existing since ADR-036), SEC-G-E1.** A sentence that cites any supported claim is not
   checked for entailment: citing "NumPy is the fundamental package for scientific computing with Python." lets "NumPy is
   secure and recommended for all production use." pass. Exploiting it needs a prompt-injected or misbehaving model. A
   content-overlap entailment test is proposed (threshold to be measured first). Owner decision OD-6.
3. **The caveat guard was rebuilt.** The fixr4 fix for honest caveats (R4-N1) failed in R5 (D-R5-1 to 3). fixr5
   added a structural rule and a rules-labelled "NeuroSciFi note". An independent adversarial security review then found 10 bypasses
   (SEC-G-F1 Critical; F2, F3, N1, N2 High); the guard became a closed caveat grammar (`128c339`), and round 3 found no
   bypass in 0 of 73 original, 0 of 65 round-2 and about 50 new attacks: ACCEPT-with-documented-limits. It fails closed:
   some honest free-form caveats are rejected and the rules note carries the message. Fix-lane live: note in 2 of 2 runs,
   sentences kept or rejected as designed; no independent live retest of the rebuilt guard.
4. **Final gate on `4c3f209` passed:** ruff clean; 2588 passed, 6 skipped (the live-internet tests), 0 failed, 35 subtests (345 s); e2e 167 passed, 1 skipped, 0 failed (790 s); offline bench
   regenerated with 3 identical runs and unchanged headline metrics.
5. **Limitations and owner decisions** in §4 and §5, including real audio devices and handsets (BLOCKED) and PersonaPlex
   not real-time.

Everything else R4 and R5 retested passed: R1-01 (High), R1-02, R1-03, R2-01 to R2-08, R2-10, T1-18, T4-02, R4-N2,
R4-N3 and the User-Agent; R2-05 passed in R5 after `f41879e`.
