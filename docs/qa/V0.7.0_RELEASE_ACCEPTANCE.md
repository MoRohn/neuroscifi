This document judges the 0.7.0 release candidate against the 15 release criteria (`RELEASE_DECISIONS.md` §4), the 12
acceptance scenarios (S1 to S12) and the Presence acceptance checks A to L (`.omc/autopilot/spec-presence.md`). Each
judgement points to its evidence. It is a judgement from recorded evidence, not a new test run.

## Verdict

**Release candidate, ready for owner acceptance with listed limitations. Not production-ready: owner-side verification remains (real phones and handsets including the Voice check, CA install on phones, push on a real phone, root-only systemd hardening checks, Brave live with the owner's key, a real external inference provider, screen readers with people), plus the open owner decisions OD-7 to OD-11.**

The evidence supports this statement and no stronger one: the evidence guard's final review is
ACCEPT-with-documented-limits (round-8 condition met: F1–F5 in dd02f16; adv11 re-run by the integrator), and the final run on `5f28e6b` is green: `bash scripts/check.sh` 3303 passed, 18 skipped (live-service tests), 0 failed;
e2e 184 passed, 1 skipped (opt-in degraded-voice test), 0 failed; offline bench regenerated into `webcortex_bench_v070.json`, identical across 3 runs (retrieval 12/12, coverage 21/24, top answer 9/12, citation precision 193/194, verification states 29/29, safety invariants hold).

What changed since the first acceptance pass (`4c3f209`, "not accepted"):

1. **T1-07, word sense: fixed.** One sense of a name per answer (`4807d7c`); other senses are read, never cited, and a
   rules note names them; consolidation never uses set-aside sources (`d88758a`). Independent live retest R6: "When was
   Rust first released?" answered about the language in 2 of 2 runs, the game when the question names it, Python
   February 1991.
2. **SEC-G-E1, entailment: fixed; review ACCEPT-with-documented-limits.** A model sentence may say no more than the claims it cites
   (`f898fc2`). Four further review rounds each blocked and each was answered: the round-4 negation and coverage gaps,
   relayed instructions (round 5), structural rules for weak evidence, exactly backed instructions and version and
   polarity anchors (round 6), and the round-7 fail-open paths with an independent-source and a negative name oracle.
   Round 8, the final review, accepted with documented limits once its F1 to F3 landed; F1 to F5 landed in `dd02f16`,
   and the integrator re-ran its harnesses (adv11: only 2 documented limits and 2 controls accepted). The model's request
   was aligned to the guard. On the 44-answer replay with the final guard: template fallback only for the 8 empty
   answers, survival 88 %, 0 unfaithful sentences in the hand checks. Verdict: ACCEPT-with-documented-limits (round-8 condition met: F1–F5 in dd02f16; adv11 re-run by the integrator).
   The guard stays lexical, with documented limits (`DEFECT_RESOLUTION_LOG.md` O-12).
3. **News rendering: fixed** (ADR-041). R6: freshness met on every run.
4. **Bench knowledge rows: resolved** (8 → 9 restored; 9 → 7 by design, no knowledge from set-aside sources).
5. **README limitations, the owner's answers:** keyed search (Brave) built and tested offline, live NOT TESTED without
   the owner's key; voice validated on recorded human speech from public corpora, with a guided Voice check for the
   owner's hardware; Web Push with an empty payload, live with real FCM in headless Chromium; node signing and attested
   enrolment. A security review of signing and push found 1 Medium, 6 Low and a functional blocker, all fixed.
6. **R6, independent live retest at `a9f5e37`:** 9 PASS, 2 FAIL (the Brave key-file check D1 and guard sentences D5);
   all 11 defects and the setup rough edges were fixed by the polish lane with tests, not retested live.
7. **Final run on `5f28e6b`:** `bash scripts/check.sh` 3303 passed, 18 skipped (live-service tests), 0 failed; e2e 184 passed, 1 skipped (opt-in degraded-voice test), 0 failed; bench identical across 3 runs. The integrated run
   on `594e244` was also green (gate 3267 passed, e2e 184 passed).
8. **New owner decisions** (§5): Brave terms, push to every family, VAD sensitivity, news rendering default, DOI
   independence grouping.

The first pass's findings that still hold: R4 and R5 passes (R1-01 High, R1-02, R1-03, R2-01 to R2-08, R2-10, T1-18,
T4-02, R4-N2, R4-N3, the User-Agent, R2-05) and the round-3 caveat-grammar review.
