Research

Ask the individual to research the public web. Every answer sentence is quoted from a cited source or computed from them, and nothing enters accepted knowledge without your review.

Web access is off

This individual does not contact the network. Turning web access on lets research tasks ask search providers and read public pages through the safe fetcher: robots.txt is honoured, private addresses are refused, and size, time and request budgets apply. You can turn it off again under Web settings.

Ask a research question

Up to 2000 characters. Do not include private names, e-mail addresses or other personal details: the question is sent to search providers.

Autonomy

Research the individual starts on its own. It is off until you switch it on, it spends only its own daily budget, and it runs only when its records give a reason worth the expected information gain. Nothing it finds is accepted without your review.

Owner switch

Loading…

Switching on asks you to confirm, then records you as the owner who enabled it and when. Switching off is recorded too and stops new investigations at once; running ones finish or can be cancelled under Research.

Daily limits

Each day is a UTC calendar day. The two budgets are separate: when autonomy runs out, your own research is not affected, and the reverse also holds.

Only from the command line

These change the individual in ways the console does not offer. Run them where the instance file lives:

  • Re-activate an archived graph revision: nsf graph rollback --db PATH CONTEXT REVISION
  • Restore a checkpoint into a new file: nsf checkpoint restore --db PATH ID DEST
  • Read any memory kind as JSON: nsf memory --db PATH KIND
